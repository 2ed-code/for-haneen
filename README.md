# For Haneen 💗

A mobile-first Arabic romantic story experience with a Three.js fantasy garden, an interactive letter, three interactive promises, a gift reveal, and a closing hug scene.

## Run
Open `index.html` through a static web server or deploy the repository with GitHub Pages. Three.js is loaded as an ES module from jsDelivr, so an internet connection is required.

## Included
- Three.js 3D castle garden, lights, floating petals and star field
- Arabic RTL layout and responsive mobile controls
- Envelope reveal and the supplied reconciliation letter
- Interactive promise cards with personal messages
- Gift, couple hug and quiet-night finale
- Procedurally synthesized gentle ambient tones (no copyrighted recording)
